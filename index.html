1. Arrays

An array stores several values of the same type under one name. Each value has an index. A loop is how you visit every element.

1.1 Declare, fill and display

DECLARE marks[5] AS INTEGER
FOR i = 0 TO 4
  OUTPUT "Enter mark " + (i + 1)
  INPUT marks[i]
ENDFOR
FOR i = 0 TO 4
  OUTPUT marks[i]
ENDFOR

With size 5 the valid indexes are 0, 1, 2, 3, 4. Using marks[5] is out of bounds, the most common array error.

1.2 The patterns you must know

// Sum and average
SET total = 0
FOR i = 0 TO n - 1
  SET total = total + marks[i]
ENDFOR
SET average = total / n

// Largest value and its position
SET largest = marks[0]
SET pos = 0
FOR i = 1 TO n - 1
  IF marks[i] > largest THEN
    SET largest = marks[i]
    SET pos = i
  ENDIF
ENDFOR

// Linear search with a flag
SET found = FALSE
SET i = 0
WHILE i < n AND found = FALSE
  IF marks[i] = target THEN
    SET found = TRUE
    SET pos = i
  ENDIF
  SET i = i + 1
ENDWHILE
IF found THEN OUTPUT "Found at " + pos ELSE OUTPUT "Not found" ENDIF
  • Set total = 0 before the loop, never inside it.
  • Start largest from the first element, not from 0 (negative values would break it).
  • Report "not found" after the loop, never inside it.

1.3 Insert and delete (shifting elements)

An array has a fixed size, so you track how many slots are in use with count.

// Insert value at position pos (needs count < size). Shift right, starting from the END.
FOR i = count TO pos + 1 STEP -1
  SET items[i] = items[i - 1]
ENDFOR
SET items[pos] = value
SET count = count + 1

// Delete the element at pos. Shift left, starting from pos.
FOR i = pos TO count - 2
  SET items[i] = items[i + 1]
ENDFOR
SET count = count - 1

Trace (delete): items = [4, 7, 9, 3], count = 4, pos = 1. Pass i=1: items[1] = 9, giving [4, 9, 9, 3]. Pass i=2: items[2] = 3, giving [4, 9, 3, 3]. Then count = 3, so the live part is [4, 9, 3]. The stale last value is ignored because count is 3.

Shifting in the wrong direction overwrites values you still need.

1.4 Parallel arrays and two-dimensional arrays

// Parallel arrays: the same index describes the same person
DECLARE names[4] AS STRING
DECLARE marks[4] AS INTEGER
SET best = 0
FOR i = 1 TO 3
  IF marks[i] > marks[best] THEN SET best = i ENDIF
ENDFOR
OUTPUT names[best] + " has the highest mark: " + marks[best]

// 2D array: 3 rows (students) by 4 columns (tests). Row totals:
DECLARE scores[3][4] AS INTEGER
FOR r = 0 TO 2
  SET rowTotal = 0
  FOR c = 0 TO 3
    SET rowTotal = rowTotal + scores[r][c]
  ENDFOR
  OUTPUT "Student " + (r + 1) + " total: " + rowTotal
ENDFOR

Reset rowTotal inside the outer loop but before the inner one, so every row starts from zero. The first index is the row, the second is the column.

1.5 Bubble sort (with a trace)

FOR pass = 0 TO n - 2
  FOR j = 0 TO n - 2 - pass
    IF nums[j] > nums[j + 1] THEN
      SET temp = nums[j]
      SET nums[j] = nums[j + 1]
      SET nums[j + 1] = temp
    ENDIF
  ENDFOR
ENDFOR
passjcompareswap?array after
005 and 2yes[2, 5, 4]
015 and 4yes[2, 4, 5]
102 and 4no[2, 4, 5]

Start: [5, 2, 4], n = 3. The three-line swap needs temp: without it, the first assignment destroys a value.

2. File handling

A text file stores data permanently, usually one record per line with fields separated by a delimiter such as a comma. A program must open a file, read or write it, then close it. Files used here: marks.txt with lines like Naledi,72.

OperationPseudocodeNotes
Open to readOPEN "marks.txt" FOR READ AS fThe file must already exist.
Open to writeOPEN "out.txt" FOR WRITE AS fErases existing content, or creates the file.
Open to appendOPEN "log.txt" FOR APPEND AS fAdds at the end, keeps old content.
Read one lineREAD line FROM fMoves to the next line each time.
Write one lineWRITE text TO fAdds a line ending after the text.
End of file testEOF(f)TRUE when there is nothing left to read.
Does it exist?FILE_EXISTS("marks.txt")Check before reading.
CloseCLOSE fAlways. Unclosed files can lose data.
Split a lineSET parts = SPLIT(line, ",")Gives an array: parts[0], parts[1] ...

2.1 Read a file into arrays

IF NOT FILE_EXISTS("marks.txt") THEN
  OUTPUT "File not found"
  STOP
ENDIF
OPEN "marks.txt" FOR READ AS f
SET count = 0
WHILE NOT EOF(f)
  READ line FROM f
  IF line <> "" THEN                       // ignore a blank last line
    SET parts = SPLIT(line, ",")
    SET names[count] = parts[0]
    SET marks[count] = TO_INTEGER(parts[1])    // file text must be converted to a number
    SET count = count + 1
  ENDIF
ENDWHILE
CLOSE f

Trace: file lines "Naledi,72" and "Tumi,58". After line 1: names[0] = "Naledi", marks[0] = 72, count = 1. After line 2: names[1] = "Tumi", marks[1] = 58, count = 2. Everything read from a file is text, so convert numbers before calculating.

2.2 Write results to a file

OPEN "report.txt" FOR WRITE AS out
FOR i = 0 TO count - 1
  IF marks[i] >= 50 THEN SET result = "PASS" ELSE SET result = "FAIL" ENDIF
  WRITE names[i] + "," + marks[i] + "," + result TO out
ENDFOR
CLOSE out

Use WRITE the first time, and APPEND when you want to add to existing records. Choosing WRITE by mistake wipes the file.

2.3 Update or delete one record

A sequential text file cannot be edited in the middle. The standard approach: read all records into arrays, change them in memory, write the whole file back.

// Update the mark for a student
INPUT searchName
SET found = FALSE
FOR i = 0 TO count - 1
  IF names[i] = searchName THEN
    INPUT marks[i]
    SET found = TRUE
  ENDIF
ENDFOR
IF found = FALSE THEN OUTPUT "Student not found" ENDIF

// Save everything back
OPEN "marks.txt" FOR WRITE AS f
FOR i = 0 TO count - 1
  WRITE names[i] + "," + marks[i] TO f
ENDFOR
CLOSE f

To delete a record, use the shift-left routine from 1.3 before saving, or skip that record while writing.

Common file mistakes: forgetting CLOSE; opening FOR WRITE when you meant APPEND; reading a file that does not exist; testing WHILE EOF(f) instead of WHILE NOT EOF(f); forgetting to convert text to numbers; processing a blank last line as a record.

3. Object-oriented programming (OOP)

A class is a blueprint. An object is one thing built from it. A class bundles attributes (data) and methods (behaviour) together.

TermMeaning
EncapsulationKeep attributes PRIVATE and let other code change them only through methods that check the values.
ConstructorA special method that runs when an object is created and sets its starting values.
Getter, setterMethods that read or change a private attribute.
InheritanceA child class gets the attributes and methods of a parent class and can add or change some.
PolymorphismDifferent classes respond to the same method name in their own way.

3.1 A class with encapsulation

CLASS BankAccount
  PRIVATE accountNo AS STRING
  PRIVATE balance AS REAL

  CONSTRUCTOR(accNo AS STRING, opening AS REAL)
    SET accountNo = accNo
    IF opening >= 0 THEN SET balance = opening ELSE SET balance = 0 ENDIF
  ENDCONSTRUCTOR

  METHOD deposit(amount AS REAL)
    IF amount > 0 THEN SET balance = balance + amount ENDIF
  ENDMETHOD

  METHOD withdraw(amount AS REAL) RETURNS BOOLEAN
    IF amount > 0 AND amount <= balance THEN
      SET balance = balance - amount
      RETURN TRUE
    ENDIF
    RETURN FALSE
  ENDMETHOD

  METHOD getBalance() RETURNS REAL
    RETURN balance
  ENDMETHOD
ENDCLASS

// Using it
SET acc = NEW BankAccount("A100", 500)
acc.deposit(200)
IF NOT acc.withdraw(900) THEN OUTPUT "Insufficient funds" ENDIF
OUTPUT acc.getBalance()

Trace: balance starts at 500, deposit 200 gives 700, the withdrawal of 900 is refused (900 is more than 700), so the output is "Insufficient funds" and then 700. Code outside the class cannot write acc.balance = -1000 because it is private. That protection is the point of encapsulation.

3.2 Inheritance and polymorphism

CLASS Shape
  PROTECTED name AS STRING
  CONSTRUCTOR(n AS STRING)
    SET name = n
  ENDCONSTRUCTOR
  METHOD area() RETURNS REAL
    RETURN 0
  ENDMETHOD
  METHOD describe()
    OUTPUT name + " area: " + area()
  ENDMETHOD
ENDCLASS

CLASS Circle INHERITS Shape
  PRIVATE radius AS REAL
  CONSTRUCTOR(r AS REAL)
    SUPER("Circle")
    SET radius = r
  ENDCONSTRUCTOR
  OVERRIDE METHOD area() RETURNS REAL
    RETURN 3.14159 * radius * radius
  ENDMETHOD
ENDCLASS

CLASS Rectangle INHERITS Shape
  PRIVATE width AS REAL
  PRIVATE height AS REAL
  CONSTRUCTOR(w AS REAL, h AS REAL)
    SUPER("Rectangle")
    SET width = w
    SET height = h
  ENDCONSTRUCTOR
  OVERRIDE METHOD area() RETURNS REAL
    RETURN width * height
  ENDMETHOD
ENDCLASS

DECLARE shapes[2] AS Shape
SET shapes[0] = NEW Circle(2)
SET shapes[1] = NEW Rectangle(3, 4)
FOR i = 0 TO 1
  shapes[i].describe()
ENDFOR

Output: "Circle area: 12.56636" then "Rectangle area: 12". The loop calls the same describe() on both, but each object uses its own area(): that is polymorphism. SUPER(...) calls the parent's constructor. PROTECTED means the child classes may use name, but outside code may not.

3.3 A class design box

+-----------------------------+
| Student                     |
+-----------------------------+
| - name : STRING             |   - means PRIVATE
| - mark : INTEGER            |   + means PUBLIC
+-----------------------------+
| + Student(n, m)             |
| + getName() : STRING        |
| + getMark() : INTEGER       |
| + grade() : STRING          |
+-----------------------------+

A class diagram has three boxes: the name, the attributes and the methods. Know how to turn one into pseudocode and back.

Common OOP mistakes: making attributes public; no validation in the constructor or setters; forgetting NEW when creating an object; calling a method without an object (acc.deposit(5), not deposit(5)); confusing a class (the blueprint) with an object (one instance).

4. Putting all three together

A typical exam question: "Read students from a file into an array of objects, find the student with the highest mark, and save a report."

CLASS Student
  PRIVATE name AS STRING
  PRIVATE mark AS INTEGER
  CONSTRUCTOR(n AS STRING, m AS INTEGER)
    SET name = n
    SET mark = m
  ENDCONSTRUCTOR
  METHOD getName() RETURNS STRING
    RETURN name
  ENDMETHOD
  METHOD getMark() RETURNS INTEGER
    RETURN mark
  ENDMETHOD
  METHOD grade() RETURNS STRING
    IF mark >= 50 THEN RETURN "Pass" ENDIF
    RETURN "Fail"
  ENDMETHOD
ENDCLASS

DECLARE students[100] AS Student
SET count = 0

// 1. Load from file into objects
OPEN "marks.txt" FOR READ AS f
WHILE NOT EOF(f)
  READ line FROM f
  IF line <> "" THEN
    SET parts = SPLIT(line, ",")
    SET students[count] = NEW Student(parts[0], TO_INTEGER(parts[1]))
    SET count = count + 1
  ENDIF
ENDWHILE
CLOSE f

// 2. Find the best student
SET best = 0
FOR i = 1 TO count - 1
  IF students[i].getMark() > students[best].getMark() THEN SET best = i ENDIF
ENDFOR
OUTPUT "Top student: " + students[best].getName()

// 3. Save a report
OPEN "report.txt" FOR WRITE AS out
FOR i = 0 TO count - 1
  WRITE students[i].getName() + "," + students[i].getMark() + "," + students[i].grade() TO out
ENDFOR
CLOSE out

Check yourself: the file is opened, read and closed; the array holds objects; private data is reached only through methods; the loop for the best student starts at 1 because the position 0 is the starting guess; and the check on count protects against an empty file (add IF count = 0 THEN ... STOP before step 2).

5. Practice questions

Try each on paper first. Tap a question to reveal the answer.

Q1. Trace this and state the output. (Arrays) 
SET nums = [3, 8, 2, 7]
SET total = 0
FOR i = 0 TO 3
  IF nums[i] > 2 THEN SET total = total + nums[i] ENDIF
ENDFOR
OUTPUT total

Answer: 18. The values 3, 8 and 7 pass the test (3 + 8 + 7), and 2 is not greater than 2.

Q2. Count how many of 6 marks are above the average. (Arrays) 
SET total = 0
FOR i = 0 TO 5
  SET total = total + marks[i]
ENDFOR
SET average = total / 6
SET countAbove = 0
FOR i = 0 TO 5
  IF marks[i] > average THEN SET countAbove = countAbove + 1 ENDIF
ENDFOR
OUTPUT countAbove

Answer: two separate passes are needed because the average is only known after the first loop.

Q3. Insert 5 at position 1 in [4, 7, 9, 3] where the array size is 6 and count is 4. (Arrays)

Answer: shift right from the end: i=4 gives items[4] = items[3] = 3; i=3 gives items[3] = items[2] = 9; i=2 gives items[2] = items[1] = 7. Then items[1] = 5 and count = 5. Result [4, 5, 7, 9, 3].

Q4. What is the difference between opening a file FOR WRITE and FOR APPEND? (Files)

Answer: WRITE erases any existing content (or creates a new file) and starts from the beginning. APPEND keeps the existing content and adds new lines at the end.

Q5. Find the two errors. (Files) 
OPEN "names.txt" FOR READ AS f
SET count = 0
WHILE EOF(f)
  READ line FROM f
  SET count = count + 1
ENDWHILE

Answer: (1) The condition is reversed: it must be WHILE NOT EOF(f), otherwise the loop never runs. (2) There is no CLOSE f after the loop. A third improvement is to check FILE_EXISTS first.

Q6. Write pseudocode to append a line "Tumi,58" to marks.txt. (Files) 
OPEN "marks.txt" FOR APPEND AS f
WRITE "Tumi,58" TO f
CLOSE f
Q7. Why should the balance attribute be PRIVATE? (OOP)

Answer: so that no outside code can set it to an invalid value such as a negative number. Changes go through methods like deposit and withdraw, which check the rules first. This is encapsulation.

Q8. Write the methods grade() for a Student class that returns "Distinction" for 75 or more, "Pass" for 50 to 74, otherwise "Fail". (OOP) 
METHOD grade() RETURNS STRING
  IF mark >= 75 THEN
    RETURN "Distinction"
  ELSE IF mark >= 50 THEN
    RETURN "Pass"
  ENDIF
  RETURN "Fail"
ENDMETHOD
Q9. A Dog class and a Cat class both inherit from Animal, which has speak(). Explain how polymorphism applies. (OOP)

Answer: each child class overrides speak() with its own behaviour (for example Dog says "Woof", Cat says "Meow"). A loop over an array of Animal objects can call speak() on each one, and every object responds according to its own class without the loop checking the type.

Q10. Outline an algorithm to load a file of products (name,price) into an array of Product objects and display the total value. (Combined)

Answer outline: check the file exists; open FOR READ; loop WHILE NOT EOF reading each line; skip blank lines; SPLIT on the comma; convert the price with TO_INTEGER or TO_REAL; create NEW Product(name, price) and store it at products[count]; add 1 to count; CLOSE the file; then loop from 0 to count - 1 adding products[i].getPrice() to a total starting at 0; output the total.

Exam checklist

  • Say whether your arrays start at 0 or 1, and stay with it.
  • Initialise every total, count and flag before the loop.
  • Every OPEN has a matching CLOSE. Check the file exists before reading.
  • Convert file text to numbers before you calculate.
  • Keep attributes PRIVATE, validate in the constructor and the setters, and create objects with NEW.
  • Indent consistently, and trace your answer on one small example before you submit.
